# AeroGuard × Cardano — presentation

Agents pay per request on Cardano for flight outcomes any contract can verify.

## Open it
- **Mac:** double-click `open-presentation.command`. **Anywhere:** open `index.html` in Chrome, Safari or Firefox.
  It works offline, from the repository checkout. The videos come from `../../cardano/video/`, so keep the folder
  inside the repo.
- **Keys:**
  - **→ / Space** next, **←** back (or click right / left).
  - **F** fullscreen.
  - **N** speaker notes under the slide.
  - **Home / End** first / last slide. `index.html#7` opens slide 7.

## What's here
| File | What |
|---|---|
| `index.html` | 10 slides, 16:9: problem → how it works → the real paid tx (video + QR) → the response → the Aiken contract (video) → the same verdict on two chains → tADA buys cover on Base → business case → next steps (QR to the code) |
| `SPEAKER-NOTES.md` | What to say on each slide, about 2½ min (the same text as the **N** notes) |
| `DEMO.md` | Live-demo runbook: rehearsal, window layout, what to say while it waits, the fallback plan |
| `media/` | WebM copies of the three slide videos (fallback for browsers without H.264) |
| `img/` | QR codes: the paid tx on Cardanoscan, the repository |
