# Presentations

Each track has its own folder with a deck, speaker notes and a demo runbook.

| Folder | Track | Open |
|---|---|---|
| [`cardano/`](cardano/) | Cardano: agents pay per request over x402, verified by an Aiken contract | `cardano/index.html` (Mac: `cardano/open-presentation.command`) |

Decks are plain HTML: open them from the repository checkout, offline, in any modern browser. Press **F** for
fullscreen and **N** for speaker notes.
